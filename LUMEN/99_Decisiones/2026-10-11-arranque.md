# Decisiones: arranque del proyecto (2026-10-11)

## Contexto
- País: Argentina. Monotributista. Por lanzar.
- Tienda en Tiendanube. Reventa de ropa.
- Inversión: $200.000/mes. Este mes: ropa y posible estampadora.
- Cuenta de Gmail del negocio inhabilitada.

## Decisiones
1. **Mini plancha portátil para sublimar: no comprar para producción.**
   - La sublimación sirve solo para poliéster claro; no para algodón u oscuros.
   - Requiere además impresora apta, tinta y papel de sublimación.
   - Las minis suelen dar presión y temperatura despareja y superficie muy chica.
   - Verificar el modelo concreto (medidas, temperatura, watts, reseñas) antes de cualquier compra.
2. **No comprar estampadora este mes.** Validar ventas primero; probar estampado mandando a hacer DTF.
3. **Reparto del mes:** ~60–70 % stock, 10–15 % tienda/marca, 15–20 % reserva y prueba de estampado.
4. **Cuenta Gmail:** apelar una sola vez con el formulario oficial desde un dispositivo y red habituales; dejar email alternativo.
5. **Dejar de depender de Gmail personal:** dominio propio (nic.ar) + correo de dominio.
6. **Organización:** un chat por tema; resúmenes guardados en este repo.
